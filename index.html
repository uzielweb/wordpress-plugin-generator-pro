1. O Sistema de Hooks (Ganchos)

WordPress funciona através de eventos. Você não altera o core, você "pendura" seu código nos eventos existentes.

Actions (Execução) Execute algo em um momento específico. 
add_action( 'init', 'meu_setup' );
Filters (Modificação) Altere um valor antes de ser usado. 
add_filter( 'the_content', 'mudar' );
Exemplo: Prioridade e Parâmetros 
// add_action( $tag, $function, $priority, $accepted_args );
add_action( 'save_post', function( $post_id, $post, $update ) {
    if ( ! $update ) return; // Só se for atualização
    // Logica aqui...
}, 10, 3 );
2. Manipulando o Banco de Dados ($wpdb)

Para consultas personalizadas, use sempre a variável global $wpdb para segurança e compatibilidade.

global $wpdb;
$tabela = $wpdb->prefix . 'minha_tabela';

// INSERT
$wpdb->insert( $tabela, ['nome' => 'João', 'email' => 'joao@ex.com'], ['%s', '%s'] );

// SELECT (Sempre use prepare para evitar SQL Injection)
$resultado = $wpdb->get_results( $wpdb->prepare( 
    "SELECT * FROM $tabela WHERE id > %d", 10 
) );
3. AJAX do jeito certo (Localize Script)

Para usar AJAX no WP, você precisa enviar a URL do admin-ajax.php para o seu JavaScript.

// No PHP
wp_enqueue_script( 'meu-js', URL . 'script.js' );
wp_localize_script( 'meu-js', 'meu_objeto', [
    'ajax_url' => admin_url( 'admin-ajax.php' ),
    'nonce'    => wp_create_nonce( 'meu_segredo' )
]);

// No JS
$.post( meu_objeto.ajax_url, { 
    action: 'minha_funcao_ajax', 
    nonce: meu_objeto.nonce 
}, function(res) { ... });
4. Transients (Cache Simples)

Evite processamentos pesados em cada carregamento usando Transients.

if ( false === ( $dados = get_transient( 'meu_cache' ) ) ) {
    $dados = carregar_algo_pesado(); // API externa, etc.
    set_transient( 'meu_cache', $dados, HOUR_IN_SECONDS );
}
return $dados;
